# pwaos-node
provides Node.js bindings for the pwaOS Runtime Client API. It exposes the runtime's C ABI as an idiomatic JavaScript module, enabling Node.js applications to launch and manage PWAs, handle window and input events, configure network proxies and user agents, and integrate native capabilities via the pwaOS service-oriented runtime.

# BUILD
npm install
npm run build
node test/index.html

# PACK
npm pack
